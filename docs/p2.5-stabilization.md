# P2.5 Reader stabilization

P2.5 freezes the native Reader architecture before annotation and Note work.
It is a refactor/stability milestone: user-visible Reader behavior and the
WinUI layout remain unchanged.

## Shell boundaries

`MainWindow` is now composition and lifecycle only. XAML event routing is split
into focused partials, while reusable stateful behavior lives in controllers:

- `ReaderViewportController`: viewport, virtualization scroll anchors, pan and restore;
- `ReaderWindowStateController`: ReaderViewModel → toolbar/empty/busy chrome projection;
- `ReaderSidebarController`: rail visibility and mutually-exclusive sidebar tabs;
- `ReaderSearchDebouncer`: search-box debounce only.

This keeps future annotation and Note commands from accumulating in one window
code-behind file.

## Reader view-model boundary

`ReaderViewModel` still owns the Reader document state, page view-models,
layout/navigation and persistence contract. Progressive search concurrency is
moved to `ReaderSearchCoordinator`, which owns provider binding, cancellation,
generation supersession, status and streamed results.

## PDFium boundary

PDFium handle lifetime remains owned by one dispatcher-backed document session,
but implementation details are separated:

- `PdfiumPdfEngine`: engine/open lifecycle and page metrics;
- `PdfiumPdfDocumentSession`: capability contracts and document-handle lifetime;
- `PdfiumPageRenderer`: rasterization only;
- `PdfiumTextReader`: text extraction, bounds and hit-testing;
- `PdfiumOutlineReader`: bookmark/destination traversal.

No PDFium handle crosses the infrastructure boundary.

## Real-world regression and soak policy

Generated CI fixtures stay the fast deterministic gate. Real-world PDFs live
only in `tests/manual-pdf-corpus` on a developer machine and are never committed.
The manual soak harness samples working set/private memory while the tester
scrolls, searches, zooms, rotates and switches view modes.

The real-world corpus/soak pass is **not** run on every update. Run it when the
rendering/virtualization stack changes or before M3/M4 milestone releases.
