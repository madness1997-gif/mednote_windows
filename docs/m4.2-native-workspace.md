# M4.2 native Note workspace

M4.2 makes the M4.1 native Library the live persistence boundary and adds the
first editable Windows Note surface. React, HTML editing, IndexedDB and the web
SheetContent model remain outside the runtime.

## Runtime cut-over

Startup first reads the native manifest. If it does not exist, the app imports
`reader-library-v1.json` into a complete native snapshot, reloads that snapshot,
and only then switches Reader to `NativeReaderLibraryStore`. Until that explicit
cut-over succeeds, Reader remains on its legacy store and stays usable. The
legacy file is never deleted or modified.

Reader loads only Document-graph and runtime metadata. It does not hydrate Note
RTF blobs. Reader state, PDF path, annotations, viewport position and unknown
payload fields are written back into the shared Document graph while Note owns
the same manifest for hierarchy, preferences and Sheet content.

## Workspace behavior

The top switch exposes three modes:

| Current mode | F6 result |
|---|---|
| Reader | Open Note and focus its editor |
| Note | Open Reader and focus its reading surface |
| Cả hai | Keep both panes visible and move focus to the other pane |

The split divider is clamped to a 20–80% Reader share. Mode and ratio are saved
in `LibraryPreferences`. Hiding Reader first captures its anchor-based viewport;
showing it reapplies Reader state and restores that anchor. Note saves before it
is hidden and keeps a caret range per Sheet for the current process.

## Native Note surface

`NotePane` is a separate control with Notebook, Section, Page and Sheet
navigation. Metadata lists load without opening every body; only the active
Sheet RTF blob is hydrated. Navigation flushes the current editor before the
active hierarchy changes.

The editor is a WinUI `RichEditBox`. Its boundary accepts and emits RTF only,
uses Segoe UI 12 pt by default, and provides bold, italic, underline, font-size,
bullet and numbered-list commands. A 550 ms debounce persists edits through the
repository; explicit navigation and pane changes flush immediately.

Every new Notebook or Page starts with a native two-column First Aid table.
Labels and content use 12 pt text, and content cells are intentionally blank.
Adding a Sheet creates an empty 12 pt RTF document.

## Web v6 conversion

`WebV6RichEditConverter` is the concrete one-way importer adapter. A pure Core
projection extracts readable current/legacy rich-text, First Aid table and flow
fields without duplicating their plain-text counterparts. RichEdit then emits
canonical 12 pt native RTF. An opaque-only non-empty payload fails conversion,
so staged replacement cannot silently turn it into a blank Sheet.

This phase rejects web Sheets with canvas strokes or image assets instead of
silently dropping them. It also does not add an interactive import picker; the
converter plugs into the staged M4.1 import service.

## M4.3 boundary

M4.3 owns PDF crop/image insertion, Note-to-PDF source anchors, advanced First
Aid blocks and richer table/canvas behavior. Sync, installer and hardened
shutdown coordination remain M5 work.

This boundary is now implemented in
[M4.3 PDF–Note integration](m4.3-note-integration.md).
